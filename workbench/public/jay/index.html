What this tool assumes
Every field in the reference payload is required. Extra fields are rejected. An empty array leaves its item shape open; mixed arrays become a union. A single response cannot tell you which fields are optional in the real API. Edit the downloaded schema after agreeing the contract with its owner.
Inference and validation run locally. Nothing you paste is stored or sent to a server. The validator covers the schema this tool generates; it is not a general-purpose JSON Schema validator.
