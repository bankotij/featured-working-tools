What is running

The collection and product pages use the live catalogue endpoint. Cart prices, available variants and quantity limits are checked on the server. A signed, HttpOnly cookie keeps the bag for seven days. It contains item references and quantities, with no name, email or payment information.

The interface waits for the server response before showing an item as added. Unavailable variants are disabled, invalid quantities are rejected and a failed request leaves a readable error. A reload reads the bag again.

Shopify connection

The carry-set page uses the independent collection; the generic product pages can also use a connected merchant catalogue. The source includes a Shopify Storefront API adapter for product queries, cart creation, line updates and Shopify checkout handoff. It also includes a separate Online Store 2.0 theme section. The public build currently runs the independent collection because no merchant store has been connected.

A store connection supplies the real catalogue, prices, availability and checkout destination. Live Shopify checkout has not been verified here. No orders or payments are collected by the independent collection.
